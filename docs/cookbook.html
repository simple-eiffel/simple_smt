Discharge a contract fragment

-- 1 <= k and k <= n  implies  k <= n   (a real precondition-in-bounds VC)
one := smt.int_value (1)
smt.prove (one.at_most (k).conjoined (k.at_most (n)).entails (k.at_most (n)))   -- True

Reproduce the AutoProof ACCOUNT bug

Without a amount <= balance precondition, withdraw can break the invariant balance >= 0 — the exact failure the MIT AutoProof demo flags.

bal := smt.int_const ("balance"); amt := smt.int_const ("amount"); zero := smt.int_value (0)

-- VC: (balance>=0 and amount>=0 and balance' = balance-amount) => balance'>=0
buggy := bal.at_least (zero).conjoined (amt.at_least (zero)).entails (bal.minus (amt).at_least (zero))
smt.prove (buggy)             -- False  (not valid)
smt.refutation (buggy)        -- e.g. "balance -> 0  amount -> 1"  (the counterexample)

-- The fix: add the missing precondition amount <= balance
fixed := bal.at_least (zero).conjoined (amt.at_least (zero)).conjoined (amt.at_most (bal))
             .entails (bal.minus (amt).at_least (zero))
smt.prove (fixed)             -- True

Catch an under-constrained (vacuous) specification

-- A stub base64 encoder that always returns 0 satisfies "result_count >= 0" for 5 bytes:
rc := smt.int_const ("rc")
expected := smt.int_value (5).plus (smt.int_value (2)).divided_by (smt.int_value (3)).times (smt.int_value (4))
smt.assume (rc.is_equal_to (smt.int_value (0)))
smt.assume (rc.at_least (smt.int_value (0)))          -- the weak postcondition
smt.assume (rc.is_equal_to (expected).negated)
smt.is_satisfiable            -- True  => the weak spec admits a wrong answer (rc=0)

-- The real postcondition pins rc = 8 exactly; the stub no longer satisfies it.

Modular arithmetic (checksums, clocks)

-- adler32 running sums stay in [0, 65520] under mod 65521:
a2 := a.plus (byte).modulo (smt.int_value (65521))
smt.prove (a.at_least (zero).conjoined (byte.at_most (smt.int_value (255)))
             .entails (a2.at_least (zero).conjoined (a2.at_most (smt.int_value (65520)))))   -- True

-- Adding a full week never changes the day-of-week:
smt.prove (d.plus (smt.int_value (7)).modulo (smt.int_value (7)).is_equal_to (d.modulo (smt.int_value (7))))  -- True

ite for max / abs

m := smt.maximum (a, b)   -- ite(a>=b, a, b)
smt.prove (m.at_least (a).conjoined (m.at_least (b)).conjoined (m.is_equal_to (a).disjoined (m.is_equal_to (b))))  -- True

ax := smt.absolute (x)    -- ite(x>=0, x, -x)
smt.prove (ax.at_least (zero).conjoined (ax.is_equal_to (x).disjoined (ax.is_equal_to (x.opposite))))            -- True

distinct: pigeonhole and graph coloring

-- 5 pairwise-distinct pigeons cannot fit in 4 holes:
smt.assume (smt.all_distinct (<<p1, p2, p3, p4, p5>>))   -- each constrained to 1..4
smt.is_unsatisfiable          -- True (pigeonhole)

-- K3 (triangle) is 3-colorable, K4 is not:
smt.assume (smt.all_distinct (<<c1, c2, c3>>))            -- each 1..3  -> is_satisfiable
smt.assume (smt.all_distinct (<<c1, c2, c3, c4>>))        -- each 1..3  -> is_unsatisfiable

Solve and read a model

smt.assume (x.greater (smt.int_value (5)))
smt.assume (x.less (smt.int_value (8)))
if smt.is_satisfiable then print (smt.model_value (x)) end   -- "6" or "7"
