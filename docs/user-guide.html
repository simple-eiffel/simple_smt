1. What an SMT solver does

An SMT solver decides whether a logical formula, drawn from decidable theories (linear integer/real arithmetic, booleans, and more), is satisfiable — whether some assignment of values makes it true. From that one primitive you get: solving (find an assignment), proving (show a conjecture is true for all values by proving its negation unsatisfiable), and refuting (produce a concrete counterexample). simple_smt exposes all three over Z3.

2. Installation

Requires the Simple Eiffel ecosystem (SIMPLE_EIFFEL) and EiffelStudio 25.02. Z3 5.0.0 is vendored in the repository.

<library name="simple_smt" location="$SIMPLE_EIFFEL/simple_smt/simple_smt.ecf"/>

libz3.dll must sit beside the executable at runtime; the build copies it into bin/. On a fresh clone the header (Clib/z3.h) and link library (lib/libz3.lib) are already present.

/d/prod/ec.sh test -config simple_smt.ecf -target simple_smt_tests   # 56/56
./bin/test_app.exe

3. Building formulas

Start from a facade, create typed constants and literals, and combine them with fluent operators. Every operator returns a new SMT_EXPR, so formulas read like the mathematics they denote.

create smt.make
k := smt.int_const ("k")        -- an integer variable
n := smt.int_const ("n")
-- 1 <= k and k <= n
bounds := smt.int_value (1).at_most (k).conjoined (k.at_most (n))

Mixing sorts is your responsibility: compare integers with integer literals (int_value), reals with real literals (real_value "1/2").

4. Deciding satisfiability

smt.assume (bounds)
smt.assume (k.greater (smt.int_value (10)))
if smt.is_satisfiable then
    print (smt.model_value (k))     -- a witness value for k
else
    print ("no solution")
end

Decisions are lazy and memoized: is_satisfiable runs Z3 once for a given assertion set and caches the outcome; asserting more, or push/pop/reset, invalidates the cache. Querying twice, or querying then reading the model, does not re-run the solver.

5. Proving and refuting

prove (c) answers "is c valid for every assignment?" It asserts not c in a scratch scope and checks for unsat; a successful proof means no counterexample exists. It never disturbs your assertion set (postcondition assertions_unchanged).

-- Prove a contract fragment: 1 <= k and k <= n  implies  k <= n
smt.prove (bounds.entails (k.at_most (n)))            -- True

-- When a claim is false, get the witness:
smt.refutation (k.greater (n))                        -- e.g. "k -> 0  n -> 0"

6. Detecting vacuous specifications

The most valuable pattern: show a weak specification is under-constrained by finding a dumb witness that satisfies it, then show the strengthened spec rules that witness out.

-- Weak: is_sorted alone. A non-permutation like (0,0,0) satisfies it -> SAT (bug!)
smt.assume (b1.at_most (b2)); smt.assume (b2.at_most (b3))
smt.assume (is_permutation (b1, b2, b3).negated)
smt.is_satisfiable            -- True: the weak spec admits (0,0,0)

-- Strong: sorted AND permutation -> only (1,2,3) survives -> the dumb witness is gone.

This is exactly the check an AutoSpec-style tool performs to keep specifications non-vacuous.

7. Scoping with push/pop

smt.assume (k.greater (smt.int_value (0)))
smt.push
    smt.assume (k.less (smt.int_value (0)))     -- now contradictory
    smt.is_unsatisfiable                        -- True
smt.pop                                          -- back to just k > 0
smt.is_satisfiable                               -- True again

8. What Z3 can and cannot decide

  • Reliable: linear integer/real arithmetic, booleans, arrays of the supported sorts, and the mod/div/ite/distinct operators. These are decidable and fast.
  • Sometimes: nonlinear arithmetic. simple_smt tests x*x = 2 (unsat over integers, sat over reals) which Z3 decides; deeper Diophantine problems (Fermat cubic, Pell) may return unknown or not terminate.
  • Out of scope (v1): quantifiers, strings, bitvectors, optimization. The binding is structured so each is one external plus one facade feature to add.

Always treat an is_unknown result honestly — it means Z3 could not decide, not that the formula is false.
