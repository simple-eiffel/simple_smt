SIMPLE_SMT (facade)

Create with make. Owns a context and one solver.

Builders

int_const / real_const / bool_const (a_name: STRING): SMT_EXPR
int_value (a_value: INTEGER): SMT_EXPR  |  real_value (a_literal: STRING): SMT_EXPR
true_expr: SMT_EXPR  |  false_expr: SMT_EXPR
ite (a_cond, a_then, a_else: SMT_EXPR): SMT_EXPR
maximum (a, b: SMT_EXPR): SMT_EXPR  |  absolute (a: SMT_EXPR): SMT_EXPR
all_distinct (a_terms: ARRAY [SMT_EXPR]): SMT_EXPR

Pairwise "every term differs" — equivalent to Z3 distinct for a finite set. require at least two terms, all in this context.

Assertions & decision

assume (a_formula: SMT_EXPR)

Add a boolean formula to the assertion set. require same context.

is_satisfiable: BOOLEAN  |  is_unsatisfiable: BOOLEAN  |  is_unknown: BOOLEAN

Decide the current assertion set (lazy, memoized).

model_value (a_expr: SMT_EXPR): STRING

Value of a_expr in the current satisfying model; "" when none.

Proving

prove (a_conjecture: SMT_EXPR): BOOLEAN

Is the conjecture valid for all values? Asserts its negation in a scratch scope and checks for unsat. ensure assertions_unchanged.

refutation (a_conjecture: SMT_EXPR): STRING

A textual counter-model where the conjecture is false, or "" if it is valid. ensure assertions_unchanged.

Scoping & output

push  |  pop  |  reset  |  to_smtlib: STRING
context: SMT_CONTEXT  |  solver: SMT_SOLVER

SMT_EXPR

A Z3 AST node plus its owning context. Every operator returns a fresh SMT_EXPR; operands must share the context (checked by precondition).

plus / minus / times / modulo / divided_by (a_other): SMT_EXPR  |  opposite: SMT_EXPR
less / at_most / greater / at_least / is_equal_to (a_other): SMT_EXPR
conjoined / disjoined / entails / xored / iff (a_other): SMT_EXPR  |  negated: SMT_EXPR
when_true_else (a_then, a_else): SMT_EXPR  |  to_string: STRING

SMT_SOLVER

assert_formula (a_formula: SMT_EXPR)  |  assertion_count: INTEGER
decide: INTEGER  (Sat=1, Unsat=-1, Undecided=0)

Lazy memoized query: runs Z3 only when the cache is stale (is_decided false, invalidated by assert/push/pop/reset), then caches. ensure decided.

is_satisfiable / is_unsatisfiable: BOOLEAN  |  is_decided: BOOLEAN  |  last_check: INTEGER
model: detachable SMT_MODEL  (require is_decided and last_check = Sat)
push  |  pop (require has_open_scope)  |  reset  |  to_smtlib: STRING

SMT_MODEL

value_of (a_expr: SMT_EXPR): STRING

Value of an expression in this model as text (numeral or "true"/"false"); "" if it cannot be evaluated.

to_string_representation: STRING  |  dispose_model

SMT_CONTEXT

Owns the Z3 configuration and context; the factory for sorts, expressions, and solvers, and the home of all inline-C externals over z3.h. Sorts (int_sort/bool_sort/real_sort) are lazily cached. AST nodes live for the context's lifetime (no per-AST ref counting); solvers and models are ref-counted. Call dispose_context to release.

Naming notes

entails (implication) and decide (the check) avoid the Eiffel reserved keywords implies and check. Boolean connectives are conjoined/disjoined/negated for the same reason (and/or/not are keywords).
